Manual override flow

Temperature end-state behavior

These examples visualize the proposed UX without adding documentation-only labels to the GUI surface. Changing the temperature in Auto switches to Manual. Choosing another end state keeps the selected target until that condition ends. Changing temperature while an override is active keeps the current end state. Selecting Time opens a time-selection input before Time becomes active.

Initial state: the room follows Auto. The card still shows the thermostat state separately as Heating, Idle, or Off.
